# GitHub integration artwork

Original files downloaded on 9 October 2026 from GitHub's
[brand toolkit](https://brand.github.com/foundations/logo), using its
[logo archive](https://brand.github.com/GitHub_Logos.zip):

- `github.svg`: `SVG/GitHub_Invertocat_Black_Clearspace.svg`.
- `github.png`: `PNG/GitHub_Invertocat_Black_Clearspace.png`.
- `github-lockup.svg`: `SVG/GitHub_Lockup_Black_Clearspace.svg`.

Original artwork is unchanged. `media/cover.webp` renders the provided lockup
with its clear space on a white background for Grain's existing store media
format. It is an integration identifier, not Grain's own business/product logo.

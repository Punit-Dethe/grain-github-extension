# GitHub integration artwork

Original files downloaded on 9 October 2026 from GitHub's
[brand toolkit](https://brand.github.com/foundations/logo), using its
[logo archive](https://brand.github.com/GitHub_Logos.zip):

- `github.svg`: `SVG/GitHub_Invertocat_Black_Clearspace.svg`.

Original source files remain unchanged. `media/icon.png` is the existing square
mark normalized to the required 512×512 PNG using proportional Lanczos sampling;
no cropping, recoloring or generated replacement. It is an integration
identifier, not Grain's own business/product logo.
